# 素材评分筛选与排序（TASK-030 / REQ-012 子项）

## 来源

- 需求：REQ-012（素材库：项目/全局、文件夹、导入、标签、备注、评分、排序、筛选、详情）
- 台账：TASK-030/TASK-034 记录"评分筛选排序待补"；DEC-023 自动推进授权下选定的独立单项。

## 现状核实（2026-10-15）

- 评分 0-5 已可在元数据编辑器（`AssetLibraryMetadataEditor.tsx`）设置并通过后端持久化（`Rating` 字段、PATCH API）。
- 列表排序仅 `createdDesc/updatedDesc/nameAsc/sizeDesc`（`AssetLibrarySort`），筛选仅 类型/来源/关联对象。
- 详情面板、关联对象筛选已存在；后端无需改动。

## 范围

1. 排序下拉新增"评分"（ratingDesc：高分在前；未评分 0 分）。
2. 筛选 Popover 新增"评分"选项：全部 / 已评分 / 1星及以上 / 2星及以上 / 3星及以上 / 4星及以上 / 5星。
3. 纯前端改动，复用 `filterAssetLibraryItems` / `compareAssetLibraryItems` / `AssetLibrarySelect`，不改后端。

## 个人用户必要性

REQ-012 明确要求评分排序与筛选；评分编辑已可用但无列表消费，形成半成品能力。个人用户素材量大后按评分挑图是核心工作流。

## 验收标准

1. 单元测试：rating 排序（含未评分 fallback）、各评分筛选档位、与既有筛选/搜索组合。
2. 前端质量门：`pnpm -C apps/workspace lint / format / build` 及相关测试全部通过。
3. 真实浏览器验收（31431 隔离数据）：设置不同评分后，排序切换即时生效；筛选档位结果正确；取消筛选恢复；刷新后（评分来自持久化数据）行为一致；深浅主题无样式回归；弹层与页面两处入口一致。
4. 对照官方截图核实有无评分星级视觉；如官方为星级展示则同步卡片/详情的评分展示形式。

## 边界

- 不做后端 API 改动；不做评分聚合统计；官方对照若发现关联详情缺口另行登记。
