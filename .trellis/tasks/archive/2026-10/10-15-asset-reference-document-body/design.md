# TASK-164 补充设计：文档正文引用

沿既有 references API、media 服务、document 服务和消费者侧接口扩展，不新增持久化表或索引。共享 URL 解析由 generation 与 document 复用；使用现有 goldmark 解析 Markdown 图片节点，覆盖段落内图片、引用式图片并排除代码块和代码行。占位图不计入真实引用，同一文档/素材去重。

media 枚举全部生命周期项目，复用 document 的本地文稿读取，保留 documentId、文档标题、类别和来源，与既有 selection 引用合并稳定排序。读取失败返回真实错误，不能降级为空列表。读取不保存正文，不触发生成或 Agent；已知读取路径可能初始化缺失 work 目录，沿既有读取语义，验收比较已有正文/version/hash 不变。

前端保留当前详情面板，显示「文档」或「选入资源」来源；未知来源不假定为 selection。使用原有主题和截断布局。扫描是个人本地按需读取；暂不增加缓存或后台索引。
