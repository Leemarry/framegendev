## 交互流程

分镜 → 视频生成 → 工作流开关 → 新建空白工作流 / 选择模板 → 画布编辑 → 自动保存。切换分镜时按 project/document/block 隔离，切换工作流时保留原画布数据。

空白处双击 → 类型菜单 → 在点击位置创建节点。右键 → 添加节点进入相同菜单。节点拖拽改变坐标；框选后复制包含内部连线，粘贴生成独立 ID。文本粘贴创建文本节点，媒体拖入或粘贴通过项目素材上传 API 入库后创建节点。

输出端口拖向输入端口 → 校验数据类型和占用 → 建立连线。点击已有连线 → 显示“断开连线” → 确认操作才移除。删除节点同时移除相邻连线，撤销同时恢复两者。

选中节点 → 上方出现浮动工具栏，生成节点下方显示引用缩略图、提示词和模型参数；删除引用会断开对应连线。双击标题编辑名称；文本通过现有 Markdown 编辑器编辑，文本和媒体支持弹窗全屏预览、下载。修改后 500ms 防抖保存，失败保留本地修改并显示重试。

图片工具：标记、裁剪和宫格切分在浏览器处理，结果上传项目素材库并创建新图片节点；视频截取当前帧创建图片节点，原始素材保留。未实现的 AI 图片处理及音视频加工不使用假成功按钮。

从输出或输入端口拖到空白处 → 显示兼容节点菜单 → 选类型后创建并自动连接。生成节点的新引用端口接受多份类型匹配的输入，旧画布保留已有端口。多选右键可创建副本、横排/竖排/网格排列、成组和删除；Ctrl/⌘ + G 成组，Shift + Ctrl/⌘ + G 解组。分组可拖动、调整大小和改名，复制整组会重新分配父子 ID。Ctrl/⌘ + F 搜索定位节点。

缩放百分比可点击输入 20–800% 或选预设；滚轮经过百分比可缩放。小地图位于左下工具栏上方。整理画布按实测尺寸和分组边界安排依赖列，支持撤销整理。

全屏按钮展开生成弹窗至窗口大小。Esc 优先关闭上层素材对话框或画布菜单，然后退出全屏；全屏退出不清空画布。

单节点生成：选择模型 → 收集连线中的文本与媒体输出 → 校验模型配置及必填参数 → 调用现有生成 API → 轮询异步任务 → 保存候选及当前输出。点击候选切换节点输出，下游引用使用所选输出。任务 ID 随画布保存；提交响应前关闭时，重开通过节点专用会话和提交时间恢复任务。读取状态失败会显示重试提示，不伪造完成。此集成未进行真实供应商生成实测；画布新增逐步运行：按连线依赖顺序执行，每步等待用户选择候选并确认，再将选中输出用于下游；支持重新生成、重试失败步骤和停止后续步骤。队列仅当前画布会话有效，关闭画布后不提交下一步；已提交节点任务仍通过持久化任务信息恢复。服务端持续执行、运行记录与分镜候选归属仍需开发。文本节点模型提示词与输出正文独立，生成时流式展示正文并暂停编辑。

## React 组件

| 组件 | 职责 |
| --- | --- |
| `VideoGenerationDialog` | 分镜上下文、工作流开关 |
| `GenerationModalShell` | 弹窗、全屏、共享素材栏、Esc 层级 |
| `WorkflowManager` / `WorkflowTabs` / `WorkflowCreateDialog` | 工作流创建、模板、切换、重命名、删除 |
| `WorkflowCanvasEditor` | ReactFlow 画布、菜单、工具栏、自动保存、会话撤销重做 |
| `WorkflowNodeView` | 节点卡、类型端口、文本与媒体预览 |
| `WorkflowNodeSettings` | 模型目录及其参数编辑 |
| `WorkflowRunControls` | 依赖队列、逐节点人工确认、失败重试与停止后续步骤 |
| `WorkflowGroupView` | 分组名称、边框及尺寸调整 |
| `WorkflowMediaTools` | 图片标记、裁剪、宫格切分及素材上传 |
| `MaterialLibraryImportDialog` | 复用项目素材选择与上传 |

撤销重做当前保存操作名称和前后图数据，仅当前画布会话有效，最多 100 条；它不等同于跨会话持久化操作日志。3D 导演台仅保留入口并标识待接入。
