## 📋 实施策略

边分析边开发，遇到关键决策点时暂停询问用户。

**✅ 已确认的核心决策**:
1. **工作流实例独立** - 从模板创建时复制 graph，每个分镜的工作流实例完全独立
2. **素材归属分镜** - 工作流素材存储在 `shots/<shotName>/workflows/<workflowId>/assets/`
3. **操作级历史** - 撤销/重做基于操作记录（Event Sourcing），而非快照

详见：`WORKFLOW-REQUIREMENTS.md` 第3节

---

## 🎯 总体目标

完整复刻 Toonflow 的画布能力到 MediaGo，支持：
- 多对多关系：分镜 ↔ 工作流实例
- 公共工作流模板库
- 工作流专属素材隔离
- Toonflow 全部交互能力
