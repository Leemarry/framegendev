Use case: ui-mockup
Asset type: high-fidelity desktop application design concept, 16:10 landscape, 1536x1024
Primary request: Design the generation interaction for a Chinese anime/drama asset editor. Show the user filling a title and detailed content, choosing the object category, requesting multiple image candidates, and reviewing prior candidates without deleting them. The design should feel like the same official 0.1.17 workspace as a focused drawer or modal over the editor.
Scene/backdrop: a light desktop editor with the underlying “道具设置” document softly visible. A centered right-side generation drawer is open, about 520px wide, with a compact header and clear vertical flow. Keep the left navigation and document context visible enough to show where the generation belongs.
Subject: drawer header “生成图片”; fields “标题” with value “翠绿救命丹药” and “内容” containing a concise Chinese visual description; segmented category selector “角色 / 场景 / 道具” with “道具” selected; a template row “三维国漫道具 · 单物体”; number stepper set to “4 张”; action button “开始生成”. Beneath it show a progress/history section with “本次生成 4 张”, four small candidate thumbnails, statuses “生成中”, “待检查”, and “已采用”, and a subtle link “查看全部候选”. Include a small informational note “重新生成会保留历史候选，不覆盖主图”.
Interaction cues: show the primary button enabled, one candidate with a star icon and “主图”, a small “设为主图” action on an unselected candidate, and a compact cancel control “取消生成” for an in-progress run. Make clear that generation is scoped to the selected title/content and can be repeated.
Style/medium: high-fidelity product UI mockup, realistic 2D interface screenshot, polished Chinese desktop software, restrained and practical.
Composition/framing: straight-on app window, the generation drawer is the visual focus while the underlying document and right asset rail remain recognizable. Use stable form rows and enough whitespace for readable labels.
Lighting/mood: calm, trustworthy, workflow-oriented.
Color palette: white and pale cool gray surfaces, charcoal navy text, muted blue primary action, small green status accent, amber only for waiting state. Avoid purple gradients.
Text (verbatim): “生成图片”, “标题”, “翠绿救命丹药”, “内容”, “角色”, “场景”, “道具”, “三维国漫道具 · 单物体”, “4 张”, “开始生成”, “本次生成 4 张”, “生成中”, “待检查”, “已采用”, “查看全部候选”, “重新生成会保留历史候选，不覆盖主图”, “设为主图”, “主图”, “取消生成”.
Constraints: all visible interface copy must be Chinese and legible; demonstrate title-plus-content as the source of generation; show multiple candidates and history retention; include failure/cancel affordance without fake success; no external provider branding or payment UI.
Avoid: generic dashboard charts, marketing hero composition, English copy, lorem ipsum, unrelated images, destructive delete as the main action, UI text overlap, watermark.
